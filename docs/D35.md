## Terminal cần chạy

Bắt đầu tại thư mục project:

```bash
cd "$HOME/Desktop/xinviec/weekfiifileone"
git clone https://github.com/Thanhlong282828/minishop-week5.git /tmp/minishop-clean
cd /tmp/minishop-clean
composer install --no-interaction
cp .env.example .env
# Cấu hình DB local riêng theo README trước khi chạy tiếp
php artisan key:generate --no-interaction
php artisan migrate --seed --no-interaction
php artisan test --compact
```
