## Học gì trong ngày này?

EC2 là máy ảo chạy Linux; AMI là ảnh hệ điều hành. Security Group lọc lưu lượng mạng trước khi tới VPS. SSH dùng khóa riêng để quản trị. Nginx nhận HTTP/HTTPS, chuyển request PHP tới PHP-FPM; Laravel kết nối MySQL qua cấu hình .env. Public IP không có Elastic IP có thể thay đổi sau stop/start. HTTP mở cổng 80 chưa đồng nghĩa đã cài web server; mở 443 chưa đồng nghĩa đã có chứng chỉ TLS.

Tài liệu: [AWS EC2](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/concepts.html), [kết nối SSH](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/connect-linux-inst-ssh.html), [Security Groups](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-security-groups.html), [Laravel Deployment](https://laravel.com/docs/13.x/deployment), [AWS Free Tier](https://aws.amazon.com/free/free-tier-faqs/).

## 3. Sửa lỗi SSH timeout

Lần đầu SSH không tới được port 22. Rule từ Chrome chỉ cho một IP, còn IP ra internet của Terminal khác. Không kết luận lỗi khóa vì timeout xảy ra trước authentication.

Kiểm tra IP Terminal:

```bash
curl --max-time 15 --silent --show-error https://checkip.amazonaws.com
```

EC2 → Security Groups → launch-wizard-1 → Inbound rules → Edit inbound rules → chỉ sửa dòng SSH, Source Custom theo kết quả IP ở trên kèm /32 → Save rules. Giữ HTTP/HTTPS. Sau sửa, SSH thành công. Nếu dùng VPN/proxy hoặc mạng thay đổi, kiểm tra lại IP, không mở SSH 0.0.0.0/0 chỉ để chữa timeout.

## 9. HTTPS miễn phí cho IP — không cần mua domain

Nguồn đã kiểm tra ngày 19/10/2026: [Let’s Encrypt hướng dẫn Certbot IP certificates](https://letsencrypt.org/2026/03/11/shorter-certs-certbot). Chứng chỉ IP dùng profile shortlived (~6 ngày); cần tự động gia hạn. Public IP xuất hiện trong Certificate Transparency. Nếu IP AWS đổi sau stop/start thì URL/chứng chỉ cũ không áp dụng cho IP mới; phải cấp lại.

Certbot bản apt của VPS chỉ 4.0, thiếu hỗ trợ webroot IP; đã cài Certbot 5.8 trong venv riêng từ PyPI:

```bash
sudo apt-get install -y python3-venv
sudo python3 -m venv /opt/certbot
sudo /opt/certbot/bin/pip install certbot
/opt/certbot/bin/certbot --version
```

Thử ACME challenge ở staging trước; không cấu hình chứng chỉ staging lên Nginx vì trình duyệt không tin tưởng staging:

```bash
sudo /opt/certbot/bin/certbot certonly --webroot \
  --webroot-path /var/www/minishop/public \
  --ip-address 54.252.208.88 --preferred-profile shortlived \
  --non-interactive --agree-tos --register-unsafely-without-email --dry-run
```

Kết quả thử: The dry run was successful. Xin chứng chỉ thật bằng cùng lệnh bỏ --dry-run. Không cung cấp email cá nhân; trạng thái gia hạn được theo dõi bằng systemd timer/log trên máy.

Sau khi có chứng chỉ, Nginx sử dụng:

```nginx
listen 443 ssl default_server;
server_name 54.252.208.88;
ssl_certificate /etc/letsencrypt/live/54.252.208.88/fullchain.pem;
ssl_certificate_key /etc/letsencrypt/live/54.252.208.88/privkey.pem;
ssl_protocols TLSv1.2 TLSv1.3;
```

Port 80 giữ location ^~ /.well-known/acme-challenge/ để phục vụ ACME renew; các request khác chuyển 301 tới https://54.252.208.88$request_uri. PHP-FPM nhận fastcgi_param HTTPS on để Laravel sinh URL/form HTTPS.

.env production đổi APP_URL=https://54.252.208.88 và SESSION_SECURE_COOKIE=true, giữ APP_DEBUG=false, sau đó php artisan config:cache. Không đổi APP_KEY/DB credentials.

Tự động gia hạn: minishop-certbot-renew.timer chạy hai lần mỗi ngày, thêm delay ngẫu nhiên tối đa một giờ, Persistent=true. Service gọi /opt/certbot/bin/certbot renew --quiet. Deploy hook /etc/letsencrypt/renewal-hooks/deploy/reload-nginx chạy nginx -t rồi systemctl reload nginx sau khi cấp chứng chỉ mới.

Lệnh xem và thử gia hạn:

```bash
sudo systemctl list-timers minishop-certbot-renew.timer --no-pager
sudo /opt/certbot/bin/certbot renew --dry-run --run-deploy-hooks --no-random-sleep-on-renew
sudo /opt/certbot/bin/certbot certificates
sudo journalctl -u minishop-certbot-renew.service -n 50 --no-pager
curl -I https://54.252.208.88/products
```

Không dùng curl -k hoặc tắt xác minh TLS để kết luận PASS. Các mô tả HTTP/chưa có TLS ở mục trước là lịch sử bản deploy ban đầu; xem kết quả xác minh HTTPS ở cuối tài liệu.
