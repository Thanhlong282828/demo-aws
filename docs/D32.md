# D32 — Automated Testing

## Học gì?

Feature tests qua Laravel kernel + MySQL, regression và transaction rollback; ưu tiên business risk.

## Tự làm theo source

1. [tests/Feature/Week5ApiTest.php](../tests/Feature/Week5ApiTest.php) — Đọc test product, auth/token, owner, category, eager load và lỗi production.
2. [tests/Feature/Week4BusinessTest.php](../tests/Feature/Week4BusinessTest.php) — Checkout order/items/stock/cart/coupon, double checkout và terminal status.
3. [phpunit.xml](../phpunit.xml) — Database minishop_week5_test riêng; RefreshDatabase có thể xóa/reset dữ liệu test.

Đọc lần lượt, tự gõ lại phần thay đổi trên branch luyện tập; gửi request hoặc chạy test sau từng bước. Controller không tin role/user_id/total từ client. Đối chiếu response với [API docs](api.md).

## Terminal cần chạy

Bắt đầu tại thư mục project:

```bash
cd "$HOME/Desktop/xinviec/weekfiifileone"
php artisan test --compact
php artisan test --compact --filter=midcheckout_failure
php artisan test --compact --filter=test_guest_product_list_is_json_and_paginated
```
