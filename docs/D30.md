# D30 — Authentication + Authorization

## Học gì?

Phân biệt ai đang gọi với được làm gì; token hash/expire/revoke, role và ownership.

## Tự làm theo source

1. [app/Http/Controllers/Api/AuthController.php](../app/Http/Controllers/Api/AuthController.php) — Tự validate credentials, Hash::check, tạo token 8h; không invent JWT. Logout revoke token hiện tại.
2. [app/Models/User.php](../app/Models/User.php) — HasApiTokens là trait của Sanctum.
3. [Modules/Shop/app/Http/Middleware/Admin.php](../Modules/Shop/app/Http/Middleware/Admin.php) — So role ADMIN ở server trước controller.
4. [Modules/Shop/app/Http/Controllers/Api/OrderController.php](../Modules/Shop/app/Http/Controllers/Api/OrderController.php) — So chủ đơn với authenticated user, không nhận owner từ body.

Đọc lần lượt, tự gõ lại phần thay đổi trên branch luyện tập; gửi request hoặc chạy test sau từng bước. Controller không tin role/user_id/total từ client. Đối chiếu response với [API docs](api.md).

## Bằng chứng và giới hạn

Đọc [permission matrix](api-permissions.md). Có hơn 10 scenario bảo mật trong test suite: guest write/orders, user create/delete/admin orders/status, wrong login, foreign order, revoked/expired token, category writes.
