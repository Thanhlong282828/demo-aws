## Câu hỏi kiến thức và đáp án tham khảo

Cách học: tự trả lời trước, sau đó đối chiếu đáp án và source. Đáp án để ôn tập, không chứng nhận bạn đã tự làm hoặc đã đạt điểm.

**Câu 1. 401 và 403 khác nhau thế nào?**

**Đáp án:** 401: chưa xác thực được, như thiếu token, token hết hạn hoặc login sai. 403: đã xác thực nhưng không được phép, như USER xóa Product hoặc xem đơn người khác.

**Câu 2. Authentication và Authorization khác nhau thế nào?**

**Đáp án:** Authentication xác định người gọi là ai; Authorization xác định người đó được làm gì với tài nguyên. auth:sanctum kiểm token; Admin middleware và kiểm owner xử lý quyền.

**Câu 3. API token dùng để làm gì?**

**Đáp án:** Client gửi token trong Authorization: Bearer để server nhận diện user cho request được bảo vệ. Sanctum hash token trong DB; project cấp hạn8 giờ và có endpoint revoke token.

**Câu 4. Token có nên commit GitHub không?**

**Đáp án:** Không. Token có thể cho phép người khác hành động dưới danh tính tài khoản; để token ở giá trị environment local/private và để rỗng khi export collection. Nếu đã lộ phải revoke/rotate.

**Câu 5. Public endpoint là gì?**

**Đáp án:** Endpoint cho phép gọi mà không cần đăng nhập. Ví dụ GET Product/Category, nhưng vẫn cần validation, pagination và xử lý lỗi.

**Câu 6. Protected endpoint là gì?**

**Đáp án:** Endpoint yêu cầu authentication, có thể kèm role hoặc ownership. Ví dụ GET /api/orders yêu cầu token; POST Product còn yêu cầu role ADMIN.

**Câu 7. Normal User gọi Admin API phải trả gì?**

**Đáp án:** User có token hợp lệ nhưng role USER phải nhận403. Nếu thiếu token hoặc token không hợp lệ thì401, không đi thẳng vào controller ghi dữ liệu.

**Câu 8. User A xem Order của B là authentication hay authorization problem?**

**Đáp án:** Là authorization, cụ thể ownership: A đã được xác thực nhưng không sở hữu đơn B. Controller so order.user_id với authenticated user.id và trả403 khi không khớp.

**Câu 9. HTTPS liên quan token thế nào ở mức cơ bản?**

**Đáp án:** HTTPS mã hóa và kiểm tra tính toàn vẹn kết nối, đồng thời xác thực máy chủ qua chứng chỉ; giúp bảo vệ token trên đường truyền. HTTPS không thay thế role/owner check và không bảo vệ token bị lộ trong log/source.

**Câu 10. Hide endpoint khỏi frontend có bảo vệ API không?**

**Đáp án:** Không. Người dùng vẫn có thể gửi request trực tiếp bằng curl/Postman; backend phải tự kiểm authentication, authorization và validation ở mỗi endpoint.
