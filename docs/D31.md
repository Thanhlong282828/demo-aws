# D31 — API Design + Postman

## Học gì?

Thiết kế theo use case; naming noun, representation nhất quán; giúp developer khác gọi API từ documentation.

## Tự làm theo source

1. [Modules/Category/routes/api.php](../Modules/Category/routes/api.php) — Category public read, admin write.
2. [Modules/Shop/routes/api.php](../Modules/Shop/routes/api.php) — User own orders và admin order management tách endpoint.
3. [app/Http/Resources/OrderResource.php](../app/Http/Resources/OrderResource.php) — Đọc money_unit, khi nào items có mặt.
4. [docs/postman/Mini-Shop-API.postman_collection.json](../docs/postman/Mini-Shop-API.postman_collection.json) — Import rồi đọc headers/body/examples/test scripts.

Đọc lần lượt, tự gõ lại phần thay đổi trên branch luyện tập; gửi request hoặc chạy test sau từng bước. Controller không tin role/user_id/total từ client. Đối chiếu response với [API docs](api.md).
