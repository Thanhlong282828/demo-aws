# D29 — REST API Product

## Học gì?

Hiểu Route → Controller → Model → Resource → JSON; HTTP method, URL và status. Web controller trả Blade, API controller trả JSON.

## Tự làm theo source

1. [Modules/Product/routes/api.php](../Modules/Product/routes/api.php) — Đọc apiResource: index/show public; write qua auth:sanctum + Admin.
2. [Modules/Product/app/Http/Controllers/Api/ProductController.php](../Modules/Product/app/Http/Controllers/Api/ProductController.php) — Tự viết index với with(category), validate per_page, paginate; show model binding; store/update dùng validated(); destroy trả data:null.
3. [Modules/Product/app/Http/Requests/SaveProductRequest.php](../Modules/Product/app/Http/Requests/SaveProductRequest.php) — Áp dụng rule giá, stock, category tồn tại.
4. [app/Http/Resources/ProductResource.php](../app/Http/Resources/ProductResource.php) — Chỉ expose contract cần thiết, không serialize model tùy tiện.

Đọc lần lượt, tự gõ lại phần thay đổi trên branch luyện tập; gửi request hoặc chạy test sau từng bước. Controller không tin role/user_id/total từ client. Đối chiếu response với [API docs](api.md).
